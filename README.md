# pites-cupcakes
Aplicativo de venda de cupcakes gourmet - Projeto Integrador de Engenharia de Software

Projeto acadêmico de um aplicativo para venda online de cupcakes gourmet, desenvolvido por Alberto G. de Carvalho na disciplina Projeto Integrador Transdisciplinar em Engenharia de Software II.

Objetivo:
Permitir que clientes consultem produtos, realizem pedidos e acompanhem seu andamento, com uma área administrativa para gerenciar produtos e pedidos.

Desenvolvimento:
O projeto está em fase de revisão do planejamento. O back-end será desenvolvido em Python, com codificação tradicional.

Documentação:
Este repositório reunirá as histórias de usuário, a documentação atualizada, os diagramas, o código-fonte e os registros dos testes conforme o desenvolvimento avançar.
